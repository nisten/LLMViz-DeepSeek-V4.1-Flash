# LLMViz-DeepSeek-V4.1-Flash
An educational 3D visualization of the DeepSeek-V4.1-Flash model.

This interactively shows the model weights inside https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash and https://huggingface.co/s-zaizen/DeepSeek-V4.1-Flash-NVFP4

Live page of it here: https://nisten.github.io/LLMViz-DeepSeek-V4.1-Flash/

It is all done as a single static index.html, no tools required. You can just download the index.html and open it directly in your browser.

The volume of each shape in 3D corresponds to its estimated size in bits on disk, including quantization overhead. You can click layers to expand their weights, rotate and pan around while reading educational info about each layer.

Let me know of any inaccuracies or hallucinations from Fable.

Intended for educational purposes but feel free to use it however you want.
